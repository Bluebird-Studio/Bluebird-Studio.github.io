# Overnight game prototypes

Two isolated browser-first projects, maintained by a five-agent timed experiment.

- [Voxel Frontier](./voxel-frontier/) — first-person procedural block world; mine/place blocks.
- [Neon Streets](./neon-streets/) — neon-lit top-down driving and delivery missions.
