# Overview - Bluebird Studio

## Mission
Creative studio for games, interactive worlds, game-jam prototypes, C++/raylib and Unity gameplay experiments, Kinect/AR scanning, and creative technologies.

## Detailed Description
Investigates interactive environments, Kinect scanning, and game graphics. Highlights include KinectSchoolScanner and raylib co-op prototypes.

## Ecosystem Context
Bridges visual graphics and hardware scanning with teaching systems (DigitalChalkLab), game engines (MLCGE), and AI frameworks (Hyperspace-Intelligence).

This section acts as a canonical guide for developers and researchers exploring the organization.
